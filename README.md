## ⚡ Características de la Web App
- **Modo Estudio / Examen (Flashcards)**: Permite ocultar las respuestas para ponerte a prueba y resolver los problemas antes de ver la solución explicada.
- **Buscador Dinámico Instantáneo**: Encuentra cualquier problema al instante buscando por palabras clave (ej: *"coaxial"*, *"desfibrilador"*, *"anillo"*, *"dieléctrico"*, etc.).
- **Filtros por Semana y Categoría**: Filtra entre preguntas conceptuales de *Análisis y Lógica*, ejercicios de *Desarrollo Matemático* o problemas de *Aplicación*.
- **Renderizado Matemático KaTeX**: Todas las ecuaciones, integrales y notaciones vectoriales se visualizan en alta definición.
- **Formulario Maestro Integrado**: Fórmulas esenciales organizadas con valores de constantes y unidades del Sistema Internacional (SI).
